# Aniversário de 25 anos da Isabelly

Site da festa: abre o `index.html` pelo GitHub Pages.

## Como atualizar

Dá para marcar tarefas, adicionar itens e editar orçamentos e fornecedores direto no site.

Para o celular e o computador mostrarem a mesma coisa, vá na aba **Ajustes** e cole um token do GitHub com a permissão `gist` (pode ser o mesmo do VAT2 Estudos). As mudanças ficam salvas num Gist privado, `festa-25-anos.json`. Sem token, elas ficam só no aparelho em que foram feitas.

O `dados.json` é o ponto de partida. Se ele for atualizado depois, com data mais nova que as mudanças do site, o site passa a usar ele.

Os arquivos `.md` abaixo são o mesmo conteúdo em texto, como registro.
